# 一键角色图片自动下载 · 使用说明

## 三种用法

| 命令 | 用途 |
|------|------|
| `python auto_download.py` | 交互式下载**单个**角色（输入中文名 + 数量） |
| `python auto_download.py -f 下载名单.txt` | **批量**下载名单里的所有角色 |
| `python auto_download.py <中文名>` | **断点续传**：只补下载缺失图片（跳过浏览器） |

## 主程序：auto_download.py（推荐）
**只需输入中文名**（批量则只需一个名单文件）：

    python auto_download.py                    # 单个角色
    python auto_download.py -f 下载名单.txt      # 批量（位置参数直接给文件路径也行）

自动完成：
  - **自动查询萌娘百科**（mzh.moegirl.org.cn）获取角色的**日文名 + 英文名**
    （提取失败时才会提示手动输入日文名；显示后可回车确认或输入修正值）
  - 打开 Edge 浏览器（Playwright 模拟，登录态保存在 browser_profile/ 文件夹）
  - **第一次运行**：窗口里会出现 pixiv，请手动登录一次，登录完回程序按回车，以后免登录
  - **作品数校验**：用日文名查 pixiv 作品数，少于 600 自动改用英文名再查；
    两者都少则警告「日文名可能不对」
  - 自动搜索 pixiv、获取指定数量的 PID（**恰好取你要的数量**，不多取）
  - PID 写入 **names/<中文名>.txt**（已有则去重合并，不会丢旧 PID）
  - 自动经 i.muxmus.com 下载图片到 **W:\临时文件夹\<中文名>**

## 批量下载：名单文件格式
每行一个角色，**中文名 + 空格 + 数量**（数量可省略，默认 30）；`#` 开头是注释：

    桐藤渚 500
    白尾绘里 300
    天见和香
    # 这行是注释，不会下载

运行：`python auto_download.py -f 下载名单.txt`

批量模式特点：
  - 浏览器**只启动一次**，所有角色共用（快）
  - 名单中某个角色取名失败会**跳过并继续**，不影响其他角色
  - 结束时打印汇总表（日文名 / 作品数 / 获取 PID 数 / 是否下载完成）

### 断点续传（意外中断/断网后继续）
    python auto_download.py <中文名>

跳过浏览器，直接用 names/<中文名>.txt 补下载缺失的图片：
  - 已下载好的自动跳过，不会重复下
  - 中断留下的**损坏文件自动检测并重下**
  - 网络失败自动重试 **5 次**（退避递增；连续 4 次 404/403 判定该图永久失效，提前跳过）

注意：访问 pixiv 需要代理/VPN，运行时请先开启系统代理。

## 迁移脚本：migrate_names.py
把工作区根目录下散落的角色 PID 文件（如 凯伊、扇喜葵.txt）移入 names/ 文件夹：

    python migrate_names.py

## 目录说明
| 路径 | 用途 |
|------|------|
| names\ | 所有 <角色中文名>.txt（PID 列表），新下载的也写在这里 |
| browser_profile\ | Edge 登录态（自动生成，别删） |
| W:\临时文件夹\<中文名>\ | 图片下载目录 |
| pixiv_muxmus\ | 旧脚本默认下载目录（现已直存 W:，基本不用） |

## 旧脚本（保留备用）
- pixiv_search.js      —— 浏览器控制台手动搜 PID（旧流程第一步）
- one_click_character.py —— 旧手动流程（粘贴 PID 再下载）
- muxmus_download.py   —— 下载核心：python muxmus_download.py pid文件 -o 输出目录
- cleanup_duplicates.py —— 清理与芙莉莲目录重复的图片
